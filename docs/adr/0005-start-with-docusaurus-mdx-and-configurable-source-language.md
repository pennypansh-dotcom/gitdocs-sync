# 第一版从 Docusaurus Markdown/MDX 开始，源语言可配置

第一版官网、demo、冷启动和验收标准默认服务 Docusaurus 团队，只承诺同步 Markdown/MDX 文档页。对外主卖点使用 “Auto-sync Docusaurus docs translations”，不限制源语言；产品通过 `source_lang` 配置支持用户指定主语言。Mintlify、Nextra、Starlight、JSON UI 文案或 OpenAPI 不作为 MVP 承诺，因为这些方向会增加文件结构适配成本，而当前最强的需求信号和获客入口集中在 Docusaurus i18n。
